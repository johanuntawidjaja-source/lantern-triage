# Submission checklist

- [x] Working browser demonstration
- [x] 720 non-confidential synthetic incident reports
- [x] Data provenance, deterministic seed, and limitations documented
- [x] 50 blinded human label reviews completed before comparison
- [x] Simple keyword baseline
- [x] Probabilistic candidate model with abstention
- [x] Quality, costly misroutes, urgent misses, coverage, latency, and cost measured
- [x] Error and abstention analysis
- [x] Stricter-review policy experiment
- [x] New-category before/after experiment
- [x] Reproducible commands and automated tests
- [x] One-page business summary
- [x] Collaborator and AI-tool attribution
- [x] Privacy/security documentation and repository scanner
- [ ] Public GitHub repository created
- [ ] GitHub Pages deployment verified from a fresh browser
- [ ] Public repository URL submitted to the assessment

The final three items require publication. Do not mark the assessment submission as
complete until the public repository and live demo have both been opened successfully.
