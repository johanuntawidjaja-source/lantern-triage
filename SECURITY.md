# Security and privacy

This repository contains only fictional incident reports. The demo runs entirely
in the browser and sends no report text to a server. Do not paste real names,
addresses, phone numbers, tracking numbers, credentials, or customer data into a
public deployment. For a production deployment, add authentication, retention
controls, encryption, audit logging, and a formal data-processing review.

Report a vulnerability privately to the repository owner rather than opening a
public issue containing sensitive details.
